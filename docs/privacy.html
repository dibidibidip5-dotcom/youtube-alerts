개인정보처리방침

내 채널 알림

1. 가져오는 정보

이 도구를 설치한 사람이 구글 계정으로 승인한 범위 안에서, 그 사람 소유 유튜브 채널의 다음 정보만 읽습니다.

  • 채널 구독자 수, 조회수 등 공개 통계
  • 영상 목록과 제목, 공개 예정 시각
  • 영상에 달린 댓글
  • 유튜브 애널리틱스 시청 통계

승인 버튼을 누른 채널 외에는 아무것도 읽지 않습니다. 시청자의 개인정보를 따로 모으거나 분석하지 않습니다.

2. 쓰는 곳

읽어 온 정보는 본인의 텔레그램으로 요약해 보내는 데만 씁니다.

3. 보관과 파기

증감 계산에 필요한 숫자(구독자 수, 조회수, 이미 알린 영상·댓글의 식별자)만 저장합니다. 댓글 내용이나 시청자 정보는 저장하지 않습니다.

4. 제3자 제공

누구에게도 팔거나 넘기지 않습니다. 도구가 동작하기 위해 유튜브(구글), 텔레그램, 깃허브를 거칠 뿐입니다.

5. 구글 사용자 데이터 정책

이 앱이 구글 API로 받은 정보의 이용과 다른 앱으로의 전송은 제한 사용 요건(Limited Use)을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

6. 승인 철회

구글 계정 설정(myaccount.google.com/permissions)에서 언제든 이 앱의 접근 권한을 끊을 수 있습니다.
