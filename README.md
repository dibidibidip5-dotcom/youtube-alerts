# 내 유튜브 채널 알림

내 채널에 무슨 일이 생기면 **텔레그램으로 알려주는 도구**입니다.

| 언제 | 무엇이 오나 |
|---|---|
| 매일 아침 9시 | 구독자·조회수가 어제보다 얼마나 늘었는지 |
| 낮 동안 한 시간마다 | 새 댓글, 조회수 급상승, 구독자 돌파 |
| 매일 아침 8시 반 | 예약해 둔 영상이 언제 올라가는지 *(구글 승인을 하면)* |
| 월요일 아침 | 지난주 시청 통계 *(구글 승인을 하면)* |

컴퓨터를 꺼도 옵니다. 인터넷에 있는 무료 컴퓨터가 대신 돌려줍니다.

---

## 시작하는 법

이 폴더를 클로드(또는 코덱스)에서 열고, 이렇게 한마디만 하세요.

**"유튜브 알림 세팅해줘"**

나머지는 클로드가 합니다. 사장님은 중간에 나오는 것만 하시면 됩니다.

- 텔레그램에서 봇 하나 만들기 (3분)
- 구글에서 열쇠 하나 받기 (3분)
- 내 채널 주소 알려주기

**15분이면 끝납니다.** 코드를 건드릴 일은 없습니다.

표의 아래 두 줄(예약 영상·시청 통계)은 구글에 "내 채널이 맞다"를 증명하는 절차가
10분쯤 더 필요합니다. 안 하셔도 위 두 줄은 그대로 옵니다. 나중에 하셔도 됩니다.

---

## 돈이 드나요

들지 않습니다. 텔레그램도, 구글도, 깃허브도 이 정도 사용량은 무료입니다.
카드를 등록할 일도 없습니다.

## 채널이 여러 개여도 되나요

됩니다. 몇 개든 한꺼번에 봅니다.

## 나중에 채널을 더 넣고 싶으면

클로드에게 **"채널 하나 더 넣어줘"** 하고 주소를 주시면 됩니다.
